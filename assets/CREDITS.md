# Office assets

- `icons/*.svg`: Pixelarticons by Gerrit Halfmann, MIT license. Original SVGs, used for interface and agent status icons. License: `icons/LICENSE`. Source: https://github.com/halfmage/pixelarticons

- `roguelikeCity_magenta.png`: Kenney, Roguelike Modern City. CC0 1.0. Original file unchanged. Despite the filename, this is the transparent atlas in the original archive.
  Source: https://kenney.nl/assets/roguelike-modern-city
  Download: https://opengameart.org/content/roguelike-modern-city-pack
  See `License.txt` for the bundled license.
- `character.png`: Unnamed, 16x16 base sprites. CC0 1.0. Source reference only; the office currently draws its own clothed directional avatars.
  Source: https://opengameart.org/content/16x16-base-sprites
- `roguelikeCity_transparent.png`: original alternate atlas, retained as part of the downloaded pack; not loaded by the app.

The office is currently drawn entirely as project-native canvas art (floors, walls, furniture, characters); the Kenney atlas is kept for reference but no longer loaded.
